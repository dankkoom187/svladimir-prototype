# Прототип сайта храма св. Владимира в Новогиреево

Статическая демонстрация нового сайта: лендинг, кликабельная главная,
расписание, скриншоты и PDF.

Публикуется на GitHub Pages из ветки `gh-pages` (содержимое папки `site/`).

**Это не боевой сайт.** Формы, оплата и админка работают только в полной
версии на Django/Wagtail.
